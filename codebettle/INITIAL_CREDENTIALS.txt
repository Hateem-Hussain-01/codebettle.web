HOW TO SIGN IN (development)
----------------------------
  1. Start the app: npm run dev (from the codebettle/ folder).
  2. Open http://localhost:3000/auth/login
  3. Enter one of the dummy emails and passwords above.
  4. You are redirected to that role's dashboard.

HOW TO CHANGE A PASSWORD
------------------------
  - Any signed-in user: use the Change Password action (account settings),
    which requires the current password and signs out all other sessions.
  - If you forget a dummy account password, reset the seed data (restart the
    dev server — seed data is in-memory in Phase 1) and use the values above.
  - Official admins: use the first-run setup (Phase 2) or the password-reset
    flow once email is configured. Never ask anyone for a password in chat.

SECURITY NOTES
------------
  - The one-click demo login buttons have been removed from the login page.
  - Sessions are server-side: signing out, suspension, or a password change
    ends sessions immediately.
  - After 5 failed sign-in attempts for one email address (per IP), sign-in
    is blocked for 15 minutes.
  - Do not commit real passwords, API keys or .env.local to GitHub.
